# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead: open this repository's
**Security** tab and click **Report a vulnerability**. Only the maintainer can see the report. I'll try to reply
within a week.

## What counts

- Cookie Munch clicking anything other than a reject, "necessary only", settings or save button: for example
  Accept, or a link that leaves the page.
- The extension sending data anywhere, or a web page being able to make it do so.
- A web page being able to control the extension: its messages, its storage, or the CSS it adds to pages.
- The Mac or iPhone app loading anything other than its own bundled page.

A banner that isn't handled isn't a security problem. Please use the
[missed banner form](https://github.com/ish1620/cookie-munch/issues/new?template=missed-banner.yml) for those.

## Supported versions

Only the latest release gets fixes.
