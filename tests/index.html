Cookie Munch test pages

Each page is a mock cookie banner. The extension's script is loaded right into the page, with a stand-in for Safari's extension APIs, so these work in any browser. Open the console and run __result() on a page to see what was clicked.

With the real extension loaded in Safari, you can also open these pages there and watch the banners disappear (the copy loaded by the page and the extension's own copy don't conflict).
