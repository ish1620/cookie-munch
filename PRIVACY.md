# Privacy

Cookie Munch doesn't collect, store or send any personal data.

- **No network requests.** The extension never contacts a server, including ours (there isn't one). All of
  its rules ship inside it.
- **No analytics, no account, no ads.**
- **What it reads:** to find and answer cookie banners, it runs on the pages you visit and looks at their
  buttons and banners. It doesn't keep or send any of that.
- **What it stores, on your device only:** your settings (the mode, whether "Also hide other popups" is on, and the sites you switched it off for), a
  count of banners handled, until you leave a page what it did there (for the popup), and the name of the
  site where it last declined a banner, with the time, so that a page the decline reloads isn't declined
  again (kept for seconds: the first page it runs on afterwards removes it). Safari keeps these in the extension's own storage. Removing
  the extension deletes them.
- **Report it link:** the popup's "Report it" link opens a GitHub page in a new tab with the current site's
  name and your setup filled in: Cookie Munch's mode and version, and whether you're on a Mac, iPhone or iPad.
  Nothing is sent unless you choose to submit the issue on GitHub, under your GitHub account. GitHub's
  privacy policy applies there.
- **The Mac and iPhone app** only shows setup steps and links to the repository and the demo page, which open
  in your browser when you tap them. The app itself has no network code.
- **The demo page** (hosted on GitHub Pages) is a single static page with no outside resources. It uses no
  cookies or storage and sends nothing anywhere. GitHub's privacy policy applies to loading the page from
  GitHub Pages.

If any of this changes, this file and the changelog will say so first.
